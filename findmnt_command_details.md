# Command Name: findmnt

## 1. Description
Find a filesystem. List mounted filesystems.

## 2. Syntax
\\\ash
findmnt [options]
\\\

## 3. Options
-l, --list: List format
-k, --kernel: Search kernel mounts
-f, --fstab: Search fstab
-t, --types <list>: Limit to types

## 4. Examples
\\\ash
findmnt
findmnt -t ext4
\\\
