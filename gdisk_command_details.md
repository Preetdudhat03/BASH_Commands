# Command Name: gdisk

## 1. Description
Interactive GUID partition table (GPT) manipulator.

## 2. Syntax
\\\ash
gdisk device
\\\

## 3. Options
-l: List partition table

## 4. Examples
\\\ash
gdisk /dev/sda
gdisk -l /dev/sda
\\\

## 5. Summary
The **gdisk** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
