# Command Name: fatlabel

## 1. Description
Set or get MS-DOS filesystem label.

## 2. Syntax
\\\ash
fatlabel device [label]
\\\

## 3. Options
None

## 4. Examples
\\\ash
fatlabel /dev/sdb1 MYUSB
fatlabel /dev/sdb1
\\\

## 5. Summary
The **fatlabel** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
