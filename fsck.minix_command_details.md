# Command Name: fsck.minix

## 1. Description
Check a Minix filesystem.

## 2. Syntax
\\\ash
fsck.minix [options] device
\\\

## 3. Options
-l: List filenames
-a: Automatic repair
-v: Verbose

## 4. Examples
\\\ash
fsck.minix /dev/fd0
\\\
