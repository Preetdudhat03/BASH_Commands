# Command Name: fsck.vfat

## 1. Description
Check and repair MS-DOS filesystems (alias for fsck.fat).

## 2. Syntax
\\\ash
fsck.vfat [options] device
\\\

## 3. Options
-p: Automatic repair
-n: No-op (check only)

## 4. Examples
\\\ash
fsck.vfat /dev/sdb1
\\\

The **fsck.vfat** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
