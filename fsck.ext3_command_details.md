# Command Name: fsck.ext3

## 1. Description
Check a Linux ext3 filesystem.

## 2. Syntax
\\\ash
fsck.ext3 [options] device
\\\

## 3. Options
-p: Automatic repair
-f: Force check

## 4. Examples
\\\ash
fsck.ext3 /dev/mapper/vg-vol
\\\

## 5. Summary
The **fsck.ext3** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
