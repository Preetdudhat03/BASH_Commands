# Command Name: dmsetup

## 1. Description
Low level logical volume management. Interface with device-mapper.

## 2. Syntax
\\\ash
dmsetup command [options]
\\\

## 3. Options
ls: List devices
info: Show info
remove: Remove device
suspend: Suspend device
resume: Resume device

## 4. Examples
\\\ash
dmsetup ls
dmsetup info my_device
\\\

## 5. Summary
The **dmsetup** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
