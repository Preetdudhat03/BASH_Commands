# Command Name: fsck.msdos

## 1. Description
Check and repair MS-DOS filesystems (alias for fsck.fat).

## 2. Syntax
\\\ash
fsck.msdos [options] device
\\\

## 3. Options
-a: Automatic repair
-r: Interactive repair

## 4. Examples
\\\ash
fsck.msdos /dev/sdb1
\\\

## 5. Summary
The **fsck.msdos** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
