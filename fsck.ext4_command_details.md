# Command Name: fsck.ext4

## 1. Description
Check a Linux ext4 filesystem.

## 2. Syntax
\\\ash
fsck.ext4 [options] device
\\\

## 3. Options
-D: Optimize directories
-f: Force check
-y: Answer yes to all

## 4. Examples
\\\ash
fsck.ext4 -f /dev/sda2
\\\

## 5. Summary
The **fsck.ext4** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
