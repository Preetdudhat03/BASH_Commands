# Command Name: e4crypt

## 1. Description
Ext4 filesystem encryption utility.

## 2. Syntax
\\\ash
e4crypt command [arguments]
\\\

## 3. Options
add_key: Add a key
get_policy: Get encryption policy
set_policy: Set encryption policy

## 4. Examples
\\\ash
e4crypt add_key
e4crypt get_policy .
\\\

## 5. Summary
The **e4crypt** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
