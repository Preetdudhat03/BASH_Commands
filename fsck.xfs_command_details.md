# Command Name: fsck.xfs

## 1. Description
Do nothing, successfully. XFS checks are done at mount time.

## 2. Syntax
\\\ash
fsck.xfs [options] device
\\\

## 3. Options
None really, typically just returns 0

## 4. Examples
\\\ash
fsck.xfs /dev/sda1
\\\
