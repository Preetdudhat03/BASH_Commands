# Command Name: dmstats

## 1. Description
Device-mapper statistics management.

## 2. Syntax
\\\ash
dmstats command [options]
\\\

## 3. Options
list: List stats regions
create: Create stats region
delete: Delete stats region
report: Report statistics

## 4. Examples
\\\ash
dmstats list
dmstats create --areas 8 /dev/mapper/my_device
\\\

## 5. Summary
The **dmstats** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
