# Command Name: getcap

## 1. Description
Examine file capabilities.

## 2. Syntax
\\\ash
getcap [options] filename...
\\\

## 3. Options
-v: Verbose
-r: Recursive

## 4. Examples
\\\ash
getcap /bin/ping
getcap -r /usr/bin
\\\

## 5. Summary
The **getcap** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
