# Command Name: devlink

## 1. Description
Devlink tool. Network configuration and monitoring tool.

## 2. Syntax
\\\ash
devlink [options] object { command | help }
\\\

## 3. Options
dev: Device management
port: Port management
monitor: Monitor events
-j, --json: Output JSON

## 4. Examples
\\\ash
devlink dev show
devlink port show
\\\

## 5. Summary
The **devlink** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
