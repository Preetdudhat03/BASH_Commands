# Command Name: jfs_tune

## 1. Description
Adjust tunable file system parameters on JFS.

## 2. Syntax
\\\ash
jfs_tune [options] device
\\\

## 3. Options
-L <label>: Set label
-l: List parameters

## 4. Examples
\\\ash
jfs_tune -l /dev/sdb1
\\\

The **jfs_tune** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
