# Command Name: hdparm

## 1. Description
Get/set hard disk parameters.

## 2. Syntax
\\\ash
hdparm [options] [device]
\\\

## 3. Options
-I: ID info
-t: Timing test
-T: Cache check info
-S: Set standby

## 4. Examples
\\\ash
hdparm -I /dev/sda
hdparm -tT /dev/sda
\\\

## 5. Summary
The **hdparm** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
