# Command Name: i386

## 1. Description
Change reported architecture in new program environment and/or set personality flags.

## 2. Syntax
\\\ash
i386 [options] [program [args...]]
\\\

## 3. Options
None

## 4. Examples
\\\ash
i386 bash
i386 rpmbuild ...
\\\

## 5. Summary
The **i386** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
