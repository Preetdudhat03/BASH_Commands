# Command Name: fsck.ext2

## 1. Description
Check a Linux ext2 filesystem.

## 2. Syntax
\\\ash
fsck.ext2 [options] device
\\\

## 3. Options
-p: Automatic repair
-y: Assume yes
-n: Assume no

## 4. Examples
\\\ash
fsck.ext2 /dev/sdc1
\\\

The **fsck.ext2** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
