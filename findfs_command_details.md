# Command Name: findfs

## 1. Description
Find a filesystem by label or UUID.

## 2. Syntax
\\\ash
findfs LABEL=<label> | UUID=<uuid>
\\\

## 3. Options
None

## 4. Examples
\\\ash
findfs LABEL=Boot
findfs UUID=1234-5678
\\\

## 5. Summary
The **findfs** command is an essential tool for managing and interacting with linux systems, specifically provided as part of this documentation set.
