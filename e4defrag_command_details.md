# Command Name: e4defrag

## 1. Description
Online defragmenter for ext4 filesystem.

## 2. Syntax
\\\ash
e4defrag [options] target
\\\

## 3. Options
-c: Check fragmentation
-v: Verbose

## 4. Examples
\\\ash
e4defrag /home
e4defrag -c /var/log/syslog
\\\
